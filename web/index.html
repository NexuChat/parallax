REVOCATION LAG

Revocation in a live session can outlive the authority change.

2,499msopen-session lag Decisionplane passed Distributionplane passed Enforcementplane passed Effectsplane failed

The owner revokes a member in one live session while the member keeps a second session open. The claim must be tested in parallel because sequential runs close the open session before that assertion starts. OWASP ASVS V3 and the OWASP testing guide define active-session revocation as a control point, but there is no standard automated verifier.

A single browsing session cannot know what it is missing. A member does not know that the page it just opened should have denied them. The evidence is in the relationship between accounts.

Parallax runs seven isolated browser contexts at the same instant, changes exactly one axis from a baseline, then reads the disagreement.
